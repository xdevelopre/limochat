# Limo Chat v1.13

این بسته بر پایه فایل `index.html` ارسالی شما ساخته شده و فایل‌های پروژه همگی در یک سطح قرار دارند.

## فایل‌ها
- `index.html` رابط فعلی Limo Chat و اتصال Supabase
- `limochat-v1.13.sql` اسکریپت واحد ساخت/مهاجرت جداول، سیاست‌های RLS، توابع و bucket
- `admin.html` پنل مدیریت با احراز هویت Supabase و بررسی عضویت در `limo_admins`
- `manifest.json` و `sw.js` فایل‌های پایه PWA
- `favicon.svg` آیکون وب‌اپ

## راه‌اندازی
1. از پروژه Supabase خود نسخه پشتیبان بگیرید.
2. کل محتوای `limochat-v1.13.sql` را در SQL Editor اجرا کنید.
3. در انتهای SQL، دستور INSERT کامنت‌شده را با آیدی حساب خود تغییر دهید و اجرا کنید تا حساب شما مدیر شود:
   ```sql
   insert into public.limo_admins(user_id)
   select id from public.profiles where username='YOUR_USERNAME'
   on conflict do nothing;
   ```
4. فایل‌ها را مستقیماً در ریشه مخزن GitHub Pages قرار دهید؛ پوشه تو در تو لازم نیست.
5. پس از انتشار، صفحه را با HTTPS باز کنید. `admin.html` پنل مدیریت است.

## محدودیت‌ها و نکات امنیتی مهم
- **رمزنگاری سرتاسری (E2EE) در این نسخه پیاده‌سازی نشده است.** پیام‌های فعلی برنامه به‌صورت متن در Supabase ذخیره می‌شوند. ادعای رمزنگاری‌شدن پیام‌ها درست نیست. پیاده‌سازی E2EE واقعی به تبادل کلید بین کاربران، بازیابی امن کلید، مدیریت کلید گروه‌ها و تغییرات ساختاری در کد کلاینت نیاز دارد؛ افزودن یک کلید ثابت در مرورگر، E2EE محسوب نمی‌شود.
- چون پیام‌ها در این نسخه متن ساده‌اند، جستجوی متن سروری ممکن است؛ ولی رابط فعلی جستجوی کامل همه پیام‌ها را ارائه نمی‌کند.
- تصاویر طبق SQL فقط برای کاربران Premium، حداکثر ۵۰۰ کیلوبایت و دو تصویر در هر ۲۴ ساعت مجازند. انقضای پیام تصویر ۷۲ ساعت است. حذف زمان‌بندی‌شده فایل‌های Storage فقط در صورتی فعال می‌شود که `pg_cron` در پروژه Supabase شما در دسترس و مجاز باشد؛ پیام NOTICE در SQL Editor را بررسی کنید.
- فعال‌سازی Premium از پنل مدیر انجام می‌شود. پرداخت آنلاین واقعی و خودکار در این بسته وجود ندارد؛ برای آن درگاه پرداخت و وب‌هوک سمت سرور لازم است.
- ساخت گروه و کانال از طریق تابع `create_limo_group` در دیتابیس فراهم شده، اما کنترل‌های کامل ساخت/مدیریت گروه و کانال هنوز به رابط اصلی متصل نشده‌اند.
- پنل مدیر فقط بعد از افزودن شناسه حساب به `limo_admins` باز می‌شود. هرگز کلید `service_role` را در `index.html` یا `admin.html` قرار ندهید.
- سیاست‌های RLS را قبل از استفاده عمومی، روی پروژه Supabase خود بررسی کنید. این بسته در این محیط به پروژه Supabase شما متصل نشده و اجرای واقعی SQL، ورود، ارسال پیام، Storage و تماس‌ها از اینجا قابل آزمایش نیست.

## تغییرات Supabase
این بسته از کلید publishable موجود در فایل اصلی استفاده می‌کند. کلید publishable برای مرورگر طراحی شده است؛ امنیت داده‌ها باید با RLS و توابع دیتابیس اعمال شود.
